# Computational Problem Solving in Python 🐍

Welcome to my repository for **Computational Problem Solving (Python)** from **Semester 1, B.Tech** at **PES University**. This space serves as a log of my lab programs, practice exercises, and semester assignments.

## 📌 Overview

This repository tracks my foundational journey into computer science and software development. It contains Python scripts demonstrating core programming logic, algorithms, and computational problem-solving techniques learned during Semester 1.

---

## 🛠️ Topics Covered

* **Fundamentals:** Input/Output operations, Data Types, Operators, and Expressions
* **Control Flow:** Conditional statements (`if-elif-else`), Loops (`for`, `while`), and Flow Control
* **Data Structures:** Operations on Lists, Tuples, Dictionaries, Sets, and String Methods
* **Modular Code:** User-defined Functions, Scopes, Parameters, and Recursion
* **Algorithms:** Searching (Linear, Binary) and Sorting (Bubble, Selection)
* **File Handling:** Reading and writing external text files (`.txt`)
